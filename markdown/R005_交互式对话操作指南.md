# R005 交互式对话操作指南

> 部署完成后，如何在 R005 上与模型进行键盘输入的交互式对话。

---

## 部署完成后你会得到什么

运行部署脚本后，系统会自动创建以下对话工具：

### Qwen3.5-2B 部署后

```

├── start_server.sh      # 启动服务
├── test_chat.sh         # 一键测试（自动问3个问题）
├── chat.py              # ← 交互式对话（键盘输入）
└── api_client.py        # Python编程调用
```

```
~/ai-r005-robobrain/
├── start_server.sh      # 启动服务
├── test_vision.sh       # 一键测试
├── chat.py              # ← 交互式对话（支持文本+图片）
└── vision_client.py     # Python编程调用
```

```bash

```

**界面示例：**
```
===== Qwen3.5-2B 交互对话 =====
输入 'quit' 退出

你 > 用Python写一个快速排序
AI > ```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```

你 > /clear
[上下文已清空]

你 > quit

```

## 方式二：curl 命令行（快速测试）

不需要 Python，直接用 curl：

```bash
# 单次对话
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5-2b",
    "messages": [{"role": "user", "content": "你好"}],
    "temperature": 0.7,
    "max_tokens": 256
  }'

# 带历史的多轮对话
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5-2b",
    "messages": [
      {"role": "user", "content": "我叫小明"},
      {"role": "assistant", "content": "你好小明！"},
      {"role": "user", "content": "我叫什么名字？"}
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'
```

## 常见问题

### Q1: chat.py 报错 "Connection refused"

服务没启动。先运行：
```bash
bash ~/ai-r005-qwen35/start_server.sh
# 等30秒再试
```

### Q2: 输入后很久没反应

R005 ARM CPU 推理较慢，第一个 token 可能需要 5~15 秒。耐心等待。

### Q3: 怎么传入图片给 Qwen3.5-2B？

Qwen3.5-2B 的 `chat.py` 是纯文本对话。如需图片，用 `api_client.py`：

```python
from api_client import QwenClient
client = QwenClient()
print(client.vision_reason(image_b64, "描述图片"))
```

或直接用 RoboBrain 的 `chat.py`，支持 `/image` 命令。

### Q4: 对话中怎么清空前文？

输入 `/clear` 即可清空上下文历史。

### Q5: 两个模型同时运行时怎么切换对话？

```bash
# 对话1: Qwen3.5-2B (端口 8080)
python3 ~/ai-r005-qwen35/chat.py

# 对话2: RoboBrain (端口 8081)
# 修改 chat.py 里的 API 端口为 8081
API = "http://localhost:8081/v1/chat/completions"
python3 ~/ai-r005-robobrain/chat.py
```
